# ADR 0011. LiteLLM Proxy только для разработчиков

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 11

## Контекст

2–3 разработчикам нужны персональные ключи, лимиты и учёт запросов к модели кодинга.

## Решение

`dev-gateway` — LiteLLM Proxy перед `llm-coder`; чат через него не ходит.

## Отвергнутые альтернативы

Свой шлюз.

## Последствия

Виртуальные ключи, лимиты и учёт без своей разработки. Enterprise-функции LiteLLM не используем.
