# ADR 0009. Генерация файлов к запуску — MCP-инструменты corp-files, песочница — после запуска

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 9

## Контекст

Нужны DOCX, XLSX, PPTX по корпоративным шаблонам. Песочница WeKnora требует Docker-сокет.

## Решение

`corp-files`: pandoc, python-docx, openpyxl, python-pptx, LibreOffice headless. Песочница кода — этап 11 (★).

## Отвергнутые альтернативы

Навыки в песочнице WeKnora для всех — тяжелее в эксплуатации и безопасности.

## Последствия

Не нужна песочница с Docker-сокетом в каждом личном пространстве. Возможности генерации ограничены набором инструментов.
