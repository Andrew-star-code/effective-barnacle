# ADR 0003. Вход — Keycloak с федерацией AD, в WeKnora — OIDC

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 3

## Контекст

В WeKnora нет LDAP. Нужны форма входа, атрибуты AD, блокировка при переборе, журнал входов, отзыв сессий.

## Решение

Keycloak проверяет пароль в AD (LDAPS, READ_ONLY), WeKnora входит по OIDC и сопоставляет пользователя по email.

## Отвергнутые альтернативы

LDAP-провайдер патчем в Go — большой постоянный патч. Dex — нет блокировки и журнала событий.

## Последствия

Ещё один сервис и БД. Kerberos позже добавляется настройкой realm. Связка пользователя по email хрупка при смене email — см. ADR 0016.
