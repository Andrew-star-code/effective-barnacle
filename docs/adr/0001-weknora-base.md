# ADR 0001. Основа — WeKnora (MIT)

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 1

## Контекст

Чат, агенты, RAG с гибридным поиском и реранкером, разбор документов, вложения, русский интерфейс, песочница и память уже есть в WeKnora и развиваются. Писать это с нуля — основная часть объёма v1.

## Решение

Строим систему на WeKnora, закреплённой версии, со своими сервисами рядом.

## Отвергнутые альтернативы

Собственный продукт (ТЗ v1) — слишком долго. Форк Open WebUI — с v0.6.6 брендинг нельзя менять без enterprise-лицензии при более чем 50 пользователях. LibreChat (MIT) — нет уровней RAG, тот же глубокий форк.

## Последствия

Стек основы — Go + Vue 3, не наш основной. Зависим от темпа и решений WeKnora (до 1.0, несовместимые изменения). Китайский язык по умолчанию — отдельная работа (SPEC §13).

Закреплён тег `v0.9.0` (коммит `f17ee8a8`), а не коммит ветки `main`: заметки к выпуску и инструкции по обновлению идут от тега к тегу. Нужные исправления из `main` переносятся отдельными коммитами в форк (SPEC §23.1, решение № 26).
