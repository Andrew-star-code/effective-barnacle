# ADR 0008. Лимиты — прокси чат-эндпоинтов в corp-ext и auth_request в nginx

Статус: принято, уточнено 13.11.2026 (ревизия 2.1) · Источник: SPEC §2.3 и §14.3, решения № 8 и № 29

## Контекст

Нужны лимиты по сообщениям, токенам и одновременным генерациям без правок ядра WeKnora.

Первая редакция: nginx делает `auth_request` в `corp-ext`, тот резервирует слот одновременной генерации, а снимает его воркер, который раз в 15 секунд читает завершённые сообщения. У схемы три изъяна:

- слот остаётся занятым до 15 секунд после ответа — при лимите 2 третье быстрое сообщение получает ложный отказ;
- `auth_request` не знает id будущего сообщения, слот не с чем связать;
- после «Стоп» и ошибок слот висит до тайм-аута 10 минут.

Снимать слот по закрытию соединения в nginx тоже нельзя: в WeKnora есть `continue-stream`, генерация продолжается после обрыва соединения.

## Решение

- `POST /api/v1/agent-chat/*` и `POST /api/v1/knowledge-chat/*` идут через тонкий прокси в `corp-ext`: проверка JWT, блокировки и лимитов, резерв слота, передача запроса в `weknora-app` без буферизации и изменений.
- Прокси снимает слот по завершении запроса. Если соединение оборвалось при незавершённом ответе, слот держится, пока воркер не увидит `is_completed`, но не дольше 10 минут.
- Остальные запросы — через `auth_request`: блокировка пользователя, блок-лист IP, лимит загрузок.
- Списание токенов — воркером по `messages.usage`; счётчики в Redis, дубль в `corp.usage_records`.

## Отвергнутые альтернативы

- Патч лимитов в Go.
- Только `auth_request` — см. изъяны выше.
- `limit_conn` в nginx по заголовку `Authorization` — без кода, но считает по токену, а не по пользователю, не настраивается политиками и протекает через `continue-stream`.

## Последствия

Ни одной правки в ядре. `corp-ext` оказывается на пути потока ответа: стриминг через него обязан быть без буферизации и проверяется нагрузочным тестом. Новой точки отказа это не добавляет — при `auth_request` чат и так зависел от `corp-ext`. При обновлении WeKnora сверяются пути и формат чат-эндпоинтов. Разовый перерасход последним ответом допускается.
