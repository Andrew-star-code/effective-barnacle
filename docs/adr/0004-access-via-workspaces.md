# ADR 0004. Права на базы — через пространства и организации WeKnora

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 4

## Контекст

В WeKnora все участники пространства видят все его базы. Нужны три уровня доступа: общие, групповые, личные базы.

## Решение

Каждый уровень — отдельное пространство; общие и групповые базы расшариваются через организации. Личное пространство сотрудника — член нужных организаций; раскладку ведёт `corp-ext` (SPEC §7).

## Отвергнутые альтернативы

Патч прав на уровне отдельных баз внутри одного пространства — глубокая правка RBAC ядра.

## Последствия

200–300 личных пространств — проверить нагрузку на пилоте. Агент «Ассистент» живёт в каждом личном пространстве; сотрудник (Contributor) может читать его конфигурацию и создавать свои агенты — см. ADR 0013.
