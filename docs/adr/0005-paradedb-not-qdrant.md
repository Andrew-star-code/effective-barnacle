# ADR 0005. Поиск — PostgreSQL + ParadeDB, а не Qdrant

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 5

## Контекст

Драйвер Qdrant в WeKnora не считает BM25 (только совпадение токенов). Нужен настоящий BM25 с русской морфологией.

## Решение

`RETRIEVE_DRIVER=postgres`: pgvector (HNSW, halfvec) + pg_search (BM25) с русским стеммером (P-01).

## Отвергнутые альтернативы

Qdrant — пришлось бы переписывать драйвер.

## Последствия

pg_search — AGPL-3.0, нужно подтверждение юристов (SPEC §23.2, вопрос 3). Индексы живут в памяти Postgres. Русский токенизатор ставится шагом `provision --search-index` — см. ADR 0014.
