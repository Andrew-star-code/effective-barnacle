# ADR 0002. WeKnora без глубокого форка: закреплённая версия, реестр патчей, свои сервисы рядом

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 2

## Контекст

WeKnora выходит каждые 2–3 недели, до 1.0 и с несовместимыми изменениями. Глубокий форк быстро перестанет обновляться.

## Решение

Форк = тег WeKnora + короткий список коммитов `P-NN:` из реестра (`docs/patches.md`). Порядок выбора: конфигурация и API → встроенный MCP или nginx → свой сервис → патч. Новый патч согласуется отдельным ADR.

## Отвергнутые альтернативы

Свободные правки в коде WeKnora.

## Последствия

Часть требований решается менее изящно (снаружи), зато обновление — перенос коротких патчей. Нужна дисциплина реестра; `make docs-check` сверяет коммиты `P-NN:` с реестром.
