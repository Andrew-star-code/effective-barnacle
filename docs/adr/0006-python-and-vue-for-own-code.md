# ADR 0006. Свой код — Python, своя админка — Vue 3 + TDesign

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 6

## Контекст

Python — основной язык команды. Фронтенд WeKnora — Vue 3 + TDesign.

## Решение

`corp-ext` и `data-gateway` — Python 3.12 (FastAPI, uv); `corp-admin` — Vue 3 + TypeScript + TDesign, мажорные версии библиотек — как у фронтенда WeKnora.

## Отвергнутые альтернативы

React для `corp-admin` — второй фронтенд-стек.

## Последствия

Один фронтенд-стек и единый вид. Патчи во фронтенде WeKnora и `corp-admin` могут делить подходы и компоненты.
