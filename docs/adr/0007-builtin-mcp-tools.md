# ADR 0007. Корпоративные инструменты — встроенные MCP-сервисы WeKnora

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 7

## Контекст

Инструменты (файлы, репорт, SQL) должны быть доступны во всех пространствах без настройки каждого, а код — жить вне ядра.

## Решение

Сервисы `corp-files`, `corp-report`, `data-gateway` — Streamable HTTP MCP, строки `mcp_services.is_builtin = true`. Идентичность пользователя — подписанный заголовок `X-Corp-User` (P-03).

## Отвергнутые альтернативы

Инструменты в Go внутри WeKnora.

## Последствия

Нужен патч P-03 (подпись); P-04 (скрытые сервисы) — после запуска, см. ADR 0013. Строки встроенных сервисов создаются seed-миграцией напрямую в БД WeKnora (исключение SPEC §16.2).
