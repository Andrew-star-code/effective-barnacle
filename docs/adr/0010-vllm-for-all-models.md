# ADR 0010. vLLM для всех моделей

Статус: принято · Дата: 13.11.2026 · Источник: SPEC §2.3, решение № 10

## Контекст

Нужны OpenAI-совместимый API, tool calling, парсеры reasoning, prefix caching, метрики и работа под параллельной нагрузкой.

## Решение

Все модели (чат, кодинг, служебная, guard, VL, эмбеддинги, реранкер) обслуживает vLLM.

## Отвергнутые альтернативы

Ollama — слабее под параллельной нагрузкой.

## Последствия

Флаги запуска зависят от версии vLLM и проверяются по её рецепту для выбранной модели. Сумма долей памяти на GPU — не больше 0,95.
