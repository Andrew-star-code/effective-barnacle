# Реестр патчей WeKnora

Рабочая версия Приложения А из [SPEC](SPEC.md). Правила — SPEC §2.4 и §22, п. 5:
каждая правка — отдельный коммит `P-NN: …` в форке, тест к ней, строка здесь.
`make docs-check` проверяет, что каждый коммит `P-NN:` из подмодуля отмечен здесь как применённый.
